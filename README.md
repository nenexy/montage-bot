# Бот-монтажёр для Telegram

Кидаешь боту видео до 5 минут, через минуту-две получаешь смонтированный ролик:

- ✂️ **паузы и тишина вырезаются** автоматически (`silencedetect` из ffmpeg);
- 🔍 **зум на склейках**: каждый второй кусок слегка приближен, как в Reels/Shorts;
- 📝 **субтитры** с подсветкой текущего слова (faster-whisper, работает локально и бесплатно);
- 🎵 **фоновая музыка**, которая сама становится тише, когда человек говорит (sidechain-компрессия);
- 💨 **звуки на переходах** («вжух» на склейках);
- 🖼 **фото-вставки**: фото, которые прислал пользователь, выезжают снизу и плавно появляются.

Каждую функцию пользователь включает и выключает в боте командой `/settings`.

## Запуск

```bash
cd ~/Downloads/montage-bot
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python make_assets.py      # заглушки музыки и «вжуха», свои можно положить в assets/
cp .env.example .env                 # впиши BOT_TOKEN от @BotFather
.venv/bin/python bot.py
```

Отдельно ставить ffmpeg не нужно: он приходит вместе с пакетом `imageio-ffmpeg`.
При первом запуске faster-whisper скачает модель (`small` весит около 480 МБ).

## Монтаж без Telegram (для проверки)

```bash
.venv/bin/python -m montage видео.mp4 -o готово.mp4 --photo фото1.jpg --music трек.mp3
```

Флаги `--no-cut --no-zoom --no-subs --no-music --no-sfx` выключают соответствующие шаги. `--model base` переключает Whisper на модель побыстрее, но она менее точная.

## Своя музыка и звуки

- `assets/music/*.mp3`: бот берёт случайный трек, если пользователь не прислал свой. Сейчас там лежит синтезированная заглушка `demo_pad.mp3`, для заказчика её лучше заменить на треки без авторских прав.
- `assets/sfx/whoosh.wav`: звук перехода.
- `assets/fonts/*.ttf`: шрифт для субтитров. На macOS берётся системный Arial. На Linux-сервере положи сюда ttf с кириллицей и пропиши имя в `SUB_FONT`.

## Оплата через ЮKassa

Пока `PAYMENT_PROVIDER_TOKEN` пустой, бот работает бесплатно. С токеном схема такая:

- новому пользователю дарится `FREE_VIDEOS` роликов;
- когда бесплатные кончаются, бот предлагает пакеты из `PACKS` (по умолчанию 1 за 99 ₽, 5 за 399 ₽, 20 за 1290 ₽). Счёт открывается прямо в Telegram, оплатить можно картой или через СБП;
- после оплаты ролики зачисляются на баланс, и бот **сразу монтирует видео, которое ждало оплаты**;
- если монтаж упал, списанный ролик автоматически возвращается на баланс;
- платежи хранятся в `data/bot.db` с id платежа в ЮKassa, чтобы делать возвраты. Повторное уведомление об одном и том же платеже не зачисляется дважды;
- команды `/buy`, `/balance`, `/terms`, `/paysupport` (Telegram требует их у ботов с оплатой), а для админов из `ADMIN_IDS` ещё `/stats` с выручкой.

**Как подключить:**
1. Владелец бота (заказчик) регистрирует магазин в [ЮKassa](https://yookassa.ru): нужен ИП или самозанятость.
2. В @BotFather: `/mybots` → бот → **Payments** → **ЮKassa**. Есть тестовый вариант («Connect ЮKassa Test»): он выдаёт токен вида `…:TEST:…`, и с ним можно платить тестовыми картами без реальных денег.
3. Вписать токен в `.env` → `PAYMENT_PROVIDER_TOKEN=` и перезапустить бота.
4. Если магазин выбивает чеки через ЮKassa (54-ФЗ), поставить `YOOKASSA_RECEIPT=1`: бот будет спрашивать e-mail и передавать данные чека. По умолчанию стоит «без НДС» (`vat_code=1`).

Тесты оплаты прогоняются без сети: `.venv/bin/python -m pytest tests`.

## Ограничения Telegram

- Через обычный Bot API бот **скачивает файлы только до 20 МБ** и отправляет до 50 МБ. Готовый ролик бот сам пережимает, если он больше лимита.
- Для больших исходников подними свой [telegram-bot-api](https://github.com/tdlib/telegram-bot-api) сервер и укажи `TELEGRAM_API_URL`: тогда лимит станет 2 ГБ.

## Сервер

Одной копии бота хватит VPS на 2–4 ядра и 4 ГБ RAM. Ролик длиной 1 минута монтируется примерно за 30–60 секунд на CPU. Если заказов станет много, увеличь `WORKERS` в `.env`.

## Устройство

```
bot.py                — Telegram (aiogram 3): приём видео, фото, музыки, настройки
montage/pipeline.py   — весь монтаж: паузы → зум → субтитры → фото → музыка и звуки
montage/silence.py    — поиск тишины и расчёт кусков
montage/subtitles.py  — распознавание речи и ASS-субтитры
montage/ffmpeg.py     — запуск ffmpeg и получение информации о файле
make_assets.py        — генерирует заглушки звуков
```
